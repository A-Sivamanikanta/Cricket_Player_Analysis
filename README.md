# Cricket_Player_Analysis
Cricket Player Analysis

An interactive Cricket Player Analysis Dashboard designed to analyze player performance and build the best Final XI. The dashboard provides detailed batting and bowling statistics, including batting average, strike rate, runs, wickets, economy, bowling average, and dot-ball percentage.
It categorizes players into Openers, Middle Order, Finishers, All-Rounders, and Bowlers, with visual charts for easy comparison and selection of players based on their strengths and performance.
